# Real-Time E-Commerce Sales & Order Analytics

## Project Overview

This project is a real-time e-commerce sales and order analytics solution developed using Python, MySQL, SQL, and Power BI.

The project generates e-commerce order data using Python, stores the data in MySQL, performs data analysis using SQL, and presents business insights through an interactive Power BI dashboard.

## Technologies Used

- Python
- MySQL
- SQL
- Power BI

## Key KPIs

- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Order Status

## Dashboard Analysis

The Power BI dashboard provides analysis of:

- Sales Trend Over Time
- Category-wise Sales
- City-wise Sales
- Top 5 Products by Sales
- Order Status Distribution
- Order-level Details

## Python

Python is used to generate real-time e-commerce order data and insert the generated records into the MySQL database.

## SQL

SQL is used to query and analyze the e-commerce order data and generate meaningful business insights.

## Power BI

Power BI is used to create an interactive dashboard with KPIs, filters, charts, and detailed order-level analysis.
